1. Finish the current 50-school publication-discovery pilot.
2. Inspect candidate precision/recall before promotion.
3. Promote verified/high-confidence student publications.
4. Run `nsmpa research-setup`.
5. Pilot 10 support organizations and inspect fetched evidence.
6. Pilot 25 student publications through the research engine.
7. Pilot 25 benchmark professional newsrooms.
8. Tune target thresholds and query families if needed.
9. Import INN/LION/state-association newsroom data in separate batches with explicit source labels.
10. Run the national student-media census.
11. Run support/advice organization research.
12. Run professional-newsroom panels by source cohort.
13. Human-verify all high-similarity supportive and adverse findings before external use.
14. Only then calculate and publish cohort-level statistics.
